# Anime Character Hub

A cinematic, interactive anime character discovery experience.

## Direction

- Character-first visual hierarchy
- Cinematic dark interface with restrained glass surfaces
- Fast discovery through search, filters, and categories
- Rich character detail pages
- Purposeful motion and responsive layouts
- Performance and accessibility treated as first-class requirements

## Stack

Next.js App Router + TypeScript + Tailwind CSS.

Next.js 16 is the target framework generation for this project. The App Router is the current recommended routing model in the official documentation.
